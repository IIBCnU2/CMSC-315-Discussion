# Unit 3 Discussion: List Operations

## Overview

This assignment examines insertion, deletion, and searching in Python lists.

## Learning Objectives

- Insert values into a list
- Delete values from a list
- Search for values in a list
- Analyze list behavior and performance

## Requirements

1. Test insertion at the beginning, middle, and end.
2. Test deletion at the beginning, middle, and end.
3. Search for existing and missing values.
4. Demonstrate edge cases.
5. Create a real-world scenario.

While working on this assignment, I learned how Python lists handle inserting, deleting, and searching for values. I got a clearer idea of how lists shift items whenever something is added or removed. For example, inserting at the beginning or middle makes Python move a bunch of items over, while inserting at the end is quick because nothing needs to shift. I also practiced doing a basic linear search, which checks each item one at a time until it finds the value. One challenge I ran into was keeping track of how the list changed after each operation. I fixed this by printing the list after every step so I could see exactly what happened. Another challenge was dealing with invalid indexes, especially when deleting from an empty list. Adding simple index checks helped prevent errors and made the functions safer. List operations matter in real apps because performance changes depending on where items are added or removed. Playlists, shopping carts, and task lists all use these kinds of operations. Understanding how lists behave helps make programs run smoother and respond faster when users interact with them.
