# Unit 4 Discussion: Binary Search Trees

## Overview

This assignment introduces Binary Search Trees (BSTs) and recursive tree operations.

## Learning Objectives

- Build a BST
- Insert values recursively
- Search recursively
- Perform in-order traversal
- Understand BST organization

## Requirements

1. Build a BST.
2. Insert multiple values.
3. Demonstrate in-order traversal.
4. Test searching.
5. Demonstrate edge cases.
6. Create a real-world BST example.

In this assignment, I learned how a Binary Search Tree works and how important the ordering rules are. Building the BST helped me understand recursion better, especially for inserting values, searching for a number, and doing an in-order traversal to get sorted output. Seeing the tree print in order made the structure easier to picture. One challenge I ran into was getting the insert function to update the tree correctly. But they can get slow if you insert values in sorted order, because the tree becomes a long chain instead of staying balanced. This assignment showed me how much the shape of the tree affects performance.
