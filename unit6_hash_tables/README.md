# Unit 6 Discussion: Dictionaries as Hash Tables

## Overview

This assignment uses Python dictionaries to demonstrate hash table behavior.

## Learning Objectives

- Insert key-value pairs
- Retrieve values efficiently
- Update existing values
- Remove entries
- Understand hashing concepts

## Requirements

1. Create and populate a dictionary.
2. Demonstrate lookup operations.
3. Demonstrate update operations.
4. Demonstrate delete operations.
5. Test edge cases.
6. Create a real-world scenario.

## Discussion Board Reflection

After completing the programming assignment, add this reflection to your initial discussion post in LEO.

Your reflection should be approximately 150–200 words and address the following questions:

Working through this assignment helped me get a better feel for how Python dictionaries act like simple hash tables. I got hands‑on practice adding items, updating values, deleting keys, and checking what happens when you try to look up something that isn’t there. Seeing how fast dictionary lookups are made the idea of hashing a lot easier to understand. One thing that slowed me down at first was keeping track of changes as I updated and removed keys. Sometimes I’d forget what was already in the dictionary, so I started printing it after each step. That made it way easier to see what was going on and avoid mistakes. I also learned more about how hash tables work behind the scenes. A hash function turns a key into a spot in memory, which is why lookups are so quick. Collisions happen when two keys land in the same spot, and even though Python handles that for you, it helped me understand why hashing matters. Overall, this assignment made the whole idea of hash tables feel much more straightforward.
